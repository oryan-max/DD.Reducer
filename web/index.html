About Minimal Reproducer Reducer

Delta Debugging (ddmin) is an automated minimization technique designed by Andreas Zeller. Given a failing test suite, it systematically cuts out chunks of code to find the smallest self-contained subset that still reproduces the exact test failure.

Key Guarantees:

  • Header Preservation: Never deletes from the first contiguous run of import lines.
  • Failure Integrity: Candidate deletions that trigger syntax errors or timeouts are treated as non-failing and immediately reverted.
  • Source Localization: Traces the exact lines executed by the minimal reproducer to pinpoint the bug in project modules.

CLI Usage:

./reduce <path-to-test-file> [--max-iterations 300] [--timeout 5] [--localize]
